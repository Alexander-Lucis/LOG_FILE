## G4: Create a GitHub Webhook Using ngrok

Step 1: Open project folder

```
cd E:\DevOps-Practical\githubActions
```

Step 2: Create `webhook_server.js`

```
notepad webhook_server.js
```

Paste and save:

```
const http = require('http');

http.createServer((req, res) => {
    console.log("GitHub event received!");
    res.end("OK");
}).listen(3000, () => {
    console.log("Server running on port 3000");
});
```

Step 3: Start Node.js server

```
node webhook_server.js
```

Step 4: Install ngrok

Download: [ngrok download](https://ngrok.com/download)

Create account: [ngrok signup](https://dashboard.ngrok.com/signup)

Get token: [ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)

Step 5: Configure ngrok (in a second PowerShell window)

```
ngrok config add-authtoken YOUR_TOKEN
```

Step 6: Start ngrok

```
ngrok http 3000
```

Copy the HTTPS forwarding URL.

Step 7: Configure GitHub

Repository → Settings → Webhooks → Add webhook

- Payload URL: `https://your-ngrok-url`
- Content type: `application/json`
- Event: Just the push event
- Click Add webhook.

Step 8: Trigger the webhook (in a third PowerShell window)

```
cd E:\DevOps-Practical\githubActions
git add .
git commit -m "Test webhook"
git push origin main
```

Expected output

```
Server running on port 3000
GitHub event received!
```

Result: GitHub webhook triggered successfully.
