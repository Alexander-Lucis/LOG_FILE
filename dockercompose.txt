## C3 — PostgreSQL Using Dockerfile: Revision Notes
**********************************************

Step 1: Run `cd E:\DevOps-Practical\Docker-PostgreSQL` to enter the project folder.

Step 2: Create a file named `Dockerfile` and add the following configuration:
 **dockerfile**
```
FROM postgres:16
ENV POSTGRES_USER=appuser
ENV POSTGRES_PASSWORD=apppass
ENV POSTGRES_DB=appdb
EXPOSE 5432
```

Step 3: Run `docker build -t my-postgres .` to build the PostgreSQL image using the Dockerfile.

Step 4: Run `docker run -d --name postgres-db -p 5433:5432 my-postgres` to create and start the container in the background.

Step 5: Run `docker ps` to verify that the PostgreSQL container is running and the port mapping is correct.

Step 6: Run `docker exec -it postgres-db psql -U appuser -d appdb -c "SELECT current_user, current_database();"` to verify the database connection and confirm the current user and database.

Step 7: Run `docker stop postgres-db` to stop the PostgreSQL container.

Step 8: Run `docker rm postgres-db` to remove the stopped container.

Step 9: Run `docker images` to verify that the `my-postgres` image still exists.

*server.js*

const express = require("express");
const { Pool } = require("pg");

const app = express();

const pool = new Pool({
  host: process.env.DB_HOST || "postgres",
  port: 5432,
  user: process.env.DB_USER || "appuser",
  password: process.env.DB_PASSWORD || "apppass",
  database: process.env.DB_NAME || "appdb"
});

app.get("/", async (req, res) => {
  try {
    const result = await pool.query(
      "SELECT current_database(), current_user"
    );

    res.send(
      `Application connected to PostgreSQL! Database: ${result.rows[0].current_database}, User: ${result.rows[0].current_user}`
    );
  } catch (error) {
    console.error(error);
    res.status(500).send("Database connection failed");
  }
});

app.listen(3000, "0.0.0.0", () => {
  console.log("Application running on port 3000");
});


**dockerfile**

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY server.js .
EXPOSE 3000
CMD ["node", "server.js"]

**docker-compose.yml***

services:
  postgres:
    image: postgres:16
    container_name: app-postgres
    environment:
      POSTGRES_USER: appuser
      POSTGRES_PASSWORD: apppass
      POSTGRES_DB: appdb
    ports:
      - "5434:5432"
    volumes:
      - app_postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U appuser -d appdb"]
      interval: 5s
      timeout: 5s
      retries: 5

**docker-compose-yml**
  app:
    build: .
    container_name: node-postgres-app
    ports:
      - "3000:3000"
    environment:
      DB_HOST: postgres
      DB_USER: appuser
      DB_PASSWORD: apppass
      DB_NAME: appdb
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  app_postgres_data:
